# Наизусть — приложение для заучивания текстов

React + TypeScript + Vite, данные хранятся локально (IndexedDB через Dexie).

## Запуск

```
npm install
npm run dev      # разработка
npm test         # тесты логики прогресса
npm run build    # сборка в dist/
```

## Структура

- `src/logic/config.ts` — все числа: интервалы, пороги очков, очки за упражнения. Меняйте здесь.
- `src/logic/progress.ts` — очки, уровни, условия повышения и понижения (чистые функции, покрыты тестами).
- `src/logic/stats.ts` — серия дней, очки по дням, точность (чистые функции, покрыты тестами).
- `src/logic/parser.ts` — разбор текста на строки и слова.
- `src/exercises/` — упражнения (готовы все 9). Новое упражнение: компонент + запись в `index.ts` + `implemented: true` в `config.ts`.
- `src/exercises/useWordTyper.ts`, `TypedText.tsx` — общий ввод слов для «Ввода текста целиком», «Продолжи строку» и «Допиши конец строки».
- `src/logic/exercises.ts` — генерация заданий (пропуски, блоки, маски) — чистые функции, покрыты тестами.
- `src/pages/` — экраны: «Сегодня» (что повторить и что предложено сделать), «Тексты», страница текста, упражнение.
- `src/db/db.ts` — локальная база (Dexie): хуки, которые помечают изменённые записи для синхронизации, экспорт/импорт/очистка.
- `src/sync/` — облако: `client.ts` (Supabase), `sync.ts` (цикл синхронизации), `mapping.ts` (преобразования и правило слияния, покрыто тестами), `SyncProvider.tsx` (вход и автосинхронизация).
- `supabase/schema.sql` — таблицы и правила доступа для облака.
- `src/logic/backup.ts` — формат и проверка файла резервной копии (покрыто тестами).

## Бесплатный хостинг

Сборка статическая (HashRouter, `base: './'`), подойдёт GitHub Pages, Cloudflare Pages или Netlify:
команда сборки `npm run build`, папка публикации `dist`.

## Установка на телефон (PWA)

После публикации на HTTPS-хостинге приложение можно установить и использовать офлайн:

- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): «Поделиться» → «На экран «Домой»».

Обновления подхватываются автоматически: после выхода новой версии она применяется при следующем открытии.
Service worker работает только на HTTPS (и на localhost), в `npm run dev` он по умолчанию не включён;
проверить PWA локально можно так: `npm run build && npm run preview`.

## Резервные копии

Данные хранятся только в браузере. Страница «Данные» (значок ⚙ в шапке) позволяет скачать копию в JSON
и восстановить её: заменить текущие данные или добавить к ним. Раз в 14 дней на экране «Сегодня» появляется напоминание.

## Облачная синхронизация (Supabase, необязательно)

Без настройки приложение работает полностью локально. Чтобы тексты и прогресс синхронизировались между устройствами:

1. Создайте бесплатный проект на supabase.com.
2. В **SQL Editor** выполните целиком файл `supabase/schema.sql` (таблицы, триггеры, правила доступа RLS).
3. **Authentication → Providers → Email**: отключите **Confirm email**. Тогда вход работает по почте и паролю без писем
   (встроенная отправка писем в бесплатном тарифе сильно ограничена). Любой адрес можно указать без подтверждения,
   но это влияет только на вход в собственный аккаунт: чужие данные недоступны благодаря RLS.
4. **Project Settings → API**: скопируйте Project URL и anon public key в файл `.env`
   (образец: `.env.example`). На хостинге добавьте те же две переменные в настройки сборки
   (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) и пересоберите проект.
5. В приложении: ⚙ → «Облако» → создайте аккаунт или войдите.

Как это работает:

- Локальная база остаётся основной: всё работает без сети, изменения отправляются, когда она появится.
- Синхронизация запускается после входа, через несколько секунд после изменений, при возвращении в приложение и вручную.
- Тексты сливаются по правилу «побеждает более новое изменение», попытки только добавляются.
- Удаление текста распространяется на другие устройства. При выходе данные остаются на устройстве;
  при входе под другим аккаунтом приложение предложит удалить данные предыдущего.
- Бесплатные проекты Supabase «засыпают» после недели без активности. Данные не пропадают, проект включается кнопкой в панели.
- Если у вас уже есть данные на устройстве и в облаке, при первом входе они объединяются. Один и тот же текст,
  созданный независимо на двух устройствах, останется в двух экземплярах.
