# Наизусть — заучивание библейских стихов

React + TypeScript + Vite. Данные хранятся локально (IndexedDB через Dexie), синхронизация между устройствами через Supabase (необязательно).

## Запуск
```
npm install
npm run dev      # разработка
npm test         # тесты
npm run build    # сборка в dist/
```
Сборка статическая (HashRouter, `base: './'`): подойдёт Cloudflare, GitHub Pages, Netlify. Команда сборки `npm run build`, папка публикации `dist`.

## Текст Библии (Синодальный перевод)
Текст не лежит в репозитории, его нужно один раз подготовить:
```
npm run bible:build
```
Скрипт скачивает Синодальный перевод (Zefania XML, общественное достояние), проверяет, что в нём 66 книг и нет пустых глав,
и записывает `public/bible/rst/index.json` и по файлу на книгу. Результат нужно закоммитить: при сборке на хостинге скрипт не запускается.
Если скачивание не удалось, скачайте файл вручную: `npm run bible:build -- --file rus-synodal.zefania.xml`.

Скрипт исправляет расхождения источника с печатным изданием: убирает неканонические главы Даниила, приводит деление Иоиля и Даниила 5–6
к синодальному, а Псалтирь переводит на славянскую нумерацию (псалмы 9 и 10 объединяются в 9-й, 114 и 115 в 113-й, 116-й делится на 114-й и 115-й,
147-й на 146-й и 147-й, остальные с 11-го по 146-й сдвигаются на единицу; ссылки в скобках перед стихами убираются).
Если число стихов в источнике окажется другим, правка не применяется, а в отчёте появляется предупреждение.

## Как устроено обучение
**Урок** собирается автоматически (`src/lessons/generator.ts`) и состоит из упражнений на стихах:
- **Новые стихи** вводятся по порядку Библии, до двух за урок: открытие по тапу, частично скрытый текст (два ползунка), затем три несложных упражнения в случайном порядке.
- **Повторение** стихов, которые уже учатся: для каждого стиха одно дополнительное упражнение и «главное» (его сложности достаточно для роста силы). В день повторения стиху достаётся больше упражнений.
- **Ввод по памяти** один раз за урок, в конце: один, два или три стиха подряд. Чем слабее стих, тем больше слов подсказано (сила 2: 60%, сила 3: 35%, с силы 4 чистый лист), а несколько стихов подряд вводить труднее, поэтому подсказок у них меньше.
- Упражнения с ошибками повторяются в конце урока (кроме ввода по памяти).
- К пройденному уроку можно вернуться («Повторить урок» на главной).

Упражнения: открытие по тапу, частично скрытый текст, выбор пропущенных слов, «Первые буквы» (слова видны / видны не все / только пробелы),
«Соберите стих» (перетаскивание или нажатия; верным считается итоговый текст, а не расположение частей), «Расставьте части» (несколько стихов подряд, номера видны после проверки),
«Где написано» (книга, глава, стих), ввод по памяти. Вопрос «Где написано» реже, если несколько раз подряд ответом была та же книга; варианты номеров глав и стихов берутся случайно из широкого окна, правильный ответ может стоять на любом месте.

**Какие стихи попадают в урок.** Новые идут по порядку; к ним подтягиваются соседние стихи, которым пора повторяться или где была ошибка.
Стихи с силой 6 и 7 попадают в урок, только если слабых стихов не осталось совсем или им сегодня пора повторяться (по графику или с опозданием): тогда они встречаются в паре упражнений, а после успешного повторения исчезают.

### Сила и циклы (`src/logic/mastery.ts`)
**Сила (0–7):** 0 — новый, 1–2 — начал учить, 3–4 — средне, 5–6 — твёрдо, 7 — выучено.
- Сила 1–6 растёт на 1 за успешное упражнение (90% и выше), если оно достаточно сложное (узнавание поднимает до 2, вспоминание с опорой до 4, ввод по памяти выше). Ограничения «раз в день» нет.
- Ошибка снижает силу на 1 (ниже 40% на 2), но не ниже 1. Результат 70–89% силу не меняет.
- Седьмой уровень даётся, когда стих с силой 6 успешно проходит четвёртый цикл повторения (при занятиях без пропусков это 7-й день) или любой следующий.

**Циклы повторения** приходятся на дни 0, 1, 3, 7, 14, 30 и 60 от начала изучения. Первый зачёт нового стиха завершает первый цикл, второй назначается на завтра.
Следующий срок считается от дня, когда цикл действительно пройден: пропуск сдвигает все следующие циклы. Ошибка в срок снижает стадию и возвращает стих на завтра.

### Свободная практика
На вкладке «Стихи» у каждой строки есть кнопка «Тренировать»: можно самому выбрать упражнение и сложность на выбранных стихах
(`src/lessons/practice.ts`). Результат засчитывается так же, как в уроке: сила стихов меняется по общим правилам, начисляется опыт,
расписание повторений обновляется. Учебные упражнения (открытие по тапу, частично скрытый текст) без оценки. Ошибки в конце не повторяются.
В историю уроков тренировка не записывается.

## Вкладка «Стихи»
Стихи делятся по твёрдости: «Новые», «Начал учить» (1–2), «Средне» (3–4), «Твёрдо» (5–6), «Выучено» (7). Строки идут в порядке Библии,
соседние стихи одной главы и одной твёрдости склеены в диапазон. Выбор стихов: «+ Добавить» → книга → глава → стихи
(коснитесь первого и последнего, чтобы выделить отрывок).

## Профиль и облачная синхронизация (Supabase, необязательно)
Без настройки приложение работает локально. Значок ⚙ ведёт на «Профиль»: вход и регистрация по почте (при регистрации указывается имя, позже его можно изменить),
опыт, число пройденных уроков, синхронизация и удаление данных.

Подключение:
1. Создайте бесплатный проект на supabase.com.
2. В **SQL Editor** выполните целиком `supabase/schema.sql` (после обновлений приложения выполняйте его ещё раз, он дополняет схему).
3. **Authentication → Providers → Email**: отключите **Confirm email**.
4. **Project Settings → API**: скопируйте Project URL и anon public key в `.env` (образец `.env.example`). На хостинге добавьте `VITE_SUPABASE_URL`
   и `VITE_SUPABASE_ANON_KEY` в переменные сборки и пересоберите проект.

Синхронизация идёт после входа, после изменений, при возвращении в приложение и вручную. Стихи сливаются по правилу «побеждает более новое изменение»,
журнал результатов и история уроков только добавляются. Если на устройстве остались данные другого аккаунта, при входе приложение предложит их удалить.
Бесплатные проекты Supabase «засыпают» после недели без активности; данные не пропадают.

## ИИ-варианты ответов для «Пропущенных слов» (необязательно)
Для вошедших в облако пользователей неверные варианты в упражнении «Пропущенные слова» подбирает языковая модель: слова той же формы, которые звучат
в тексте естественно, но не подходят по смыслу. Без настройки (или без входа, или без сети) упражнение работает с обычными вариантами из слов главы.
Пропусков в упражнении много: от 2 на новом стихе до 7 на сильном (не больше трети слов стиха).

Бесплатный вариант без платёжных данных: **Google Gemini** (бесплатный уровень Google AI Studio):
1. Выполните `supabase/schema.sql` ещё раз (добавляется таблица `verse_options` с общим кэшем вариантов).
2. На aistudio.google.com войдите аккаунтом Google и создайте API-ключ («Get API key»). Платёжный аккаунт для бесплатного уровня не нужен.
   Если при создании ключа Google всё же потребует предоплату, значит, условия изменились: тогда используйте другой вариант (см. ниже).
3. В Supabase: **Edge Functions → Deploy a new function → Via Editor**. Назовите функцию `gap-options`, вставьте код из `supabase/functions/gap-options/index.ts` и нажмите Deploy.
   Проверку JWT («Verify JWT») оставьте включённой: тогда функцию могут вызывать только вошедшие пользователи.
4. **Edge Functions → Secrets**: добавьте секрет `GEMINI_API_KEY` с ключом из шага 2.
   Если функция отвечает ошибкой модели, задайте секрет `GEMINI_MODEL` с именем актуальной бесплатной модели из AI Studio (по умолчанию `gemini-flash-lite-latest`).
5. Готово: при добавлении стихов варианты готовятся в фоне, а при начале урока недостающие добираются (ожидание не дольше нескольких секунд, иначе используются обычные варианты).

Платная альтернатива: вместо `GEMINI_API_KEY` задайте секрет `ANTHROPIC_API_KEY` (ключ с console.anthropic.com, нужен платёжный метод). Если заданы оба ключа, сначала пробуется Gemini, при его ошибке Claude.

Что стоит знать о бесплатном уровне Gemini: у него есть ограничения по числу запросов (точные цифры показаны в AI Studio), а Google вправе использовать запросы бесплатного уровня
для улучшения своих продуктов. Приложение отправляет только текст стихов Синодального перевода, никаких личных данных.
Запрос делается один раз на стих: результат сохраняется и на устройстве, и в общей таблице в облаке.

Защита: ключи хранятся только в Supabase; один пользователь может обработать не больше 300 новых стихов в сутки; ответ модели проверяется
(слово совпадает со стихом, варианты по одному слову, без повторов и без правильного ответа).

## Установка на телефон (PWA)
Android (Chrome): меню ⋮ → «Установить приложение». iPhone (Safari): «Поделиться» → «На экран «Домой»». Работает на HTTPS, обновления подхватываются сами.

## Структура
- `src/logic/mastery.ts` — сила, циклы, правила; `src/logic/library.ts` — список «Мои стихи»; `src/logic/exercises.ts` — вспомогательные функции упражнений.
- `src/lessons/` — генератор уроков, упражнения, запуск урока; `src/exercises/` — общие компоненты ввода слов.
- `src/bible/` — книги, ссылки, загрузка текста; `scripts/` — подготовка текста Библии.
- `src/sync/` — вход и синхронизация; `src/db/db.ts` — локальная база.
